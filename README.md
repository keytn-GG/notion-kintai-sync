# notion-kintai-sync

Notion のタイムカードに記録した出勤・退勤の時刻を、会社の勤怠Excelに自動で書き込むツールです。

> **開発中です。** 導入手順や動作条件は、完成時にここへまとめます。

## できること

- 月の初めに一度だけ、勤怠Excelを複製してカレンダーを作ります（［日付設定］を自動で押します）
- その後は Notion に打刻が増えるたびに、勤務時刻を静かに書き込みます（画面には何も出ません）
- 月末を待たずに、いつでも最新の勤怠Excelが手元にあります

## 動作条件（予定）

- Windows 10 / 11、Windows版のデスクトップExcel（マクロが動くこと）
- PowerShell 5.1（Windows標準）
- Notion のタイムカード（テンプレートを複製したもの）と、読み取り専用のAPIキー

## フォルダの構成

```
notion-kintai-sync/
├─ run.cmd          手動での実行（メニュー）
├─ config/          設定（config.json と書式の設定 profile）
├─ src/             スクリプト本体
├─ workbook/        会社の勤怠Excelを置く場所（Gitで管理しない）
├─ output/          出来上がったファイル（自動で作る）
└─ logs/            ログ（自動で作る）
```
